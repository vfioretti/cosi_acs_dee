# DEE for the COSI ACS

This section contains all the files needed for the simulation, analysis, and production of a correction file for the ACS (Anticoincidence Shield) of COSI.

The correction file accounts for the impact of optical physics on light collection and energy resolution, with values specified for each spatial voxel.

### Directory Structure

- **`Simulations/`**  
  Contains the setup and scripts to run the Geant4-based simulations.

- **`Analysis/`**  
  Includes tools to analyze the simulation output and generate the spatial correction file.
