# Benchmarking tutorial

This is a quick tutorial on how to simulate a radioactive source, analyze the response of the ACS lateral wall and compare the results with laboratory data. 

There are three steps: simulation, analysis and comparison. Each step has its own dedicated directory:
- **Simulations**: in this directory, you can learn how to simulate a radioactive source. In this example you will simulate Cesium-137 (Cs137), both uncollimated and collimated
- **Analysis**: in this directory, you can learn how to analyze the response of the ACS lateral wall to the simulated radioactive sources.
- **Comparison**: in this directory, you can learn how to perform an energy calibration to simulated data to get energy spectra for each radioactive sources. Also, if available, you can learn how to energy calibrate laboratory data and compare the resulting experimental spectra to the simulated ones.
