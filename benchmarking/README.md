# Geant4 simulation benchmarking

This is the section for the COSI ACS simulation benchmarking. This is the description of the directories:

- **NRL_SSL_benchmarking**: here you can find a collection of files used for the simulation benchmarking using NRL and SSL data (Ciabattoni et al. 2025)
- **python_scripts**: this is a collection of python scripts used for the benchmarking
- **geom**: here you can find the geometry files used for the benchmarking and a description of the simulated mass model
- **phys**: here you can find the physics files used for the benchmarking
- **cad_files**: here you can find the CAD files used for the benchmarking
- **tutorial**: here you can find a tutorial on how to simulate a radioactive source, peform the energy calibration and compare the results with experimental data
